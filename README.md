## What I do

- **Websites and web apps:** WordPress or Shopify when you need to launch fast, custom builds with Django, React or Next.js when you need more.
- **Dashboards and data:** Power BI dashboards, automated SQL and Excel reporting, Python data pipelines.
- **SEO and analytics:** audits, tracking setup and monthly reporting.
